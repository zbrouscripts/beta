# Ajustes recomendados de GitBook

Estos ajustes se hacen desde GitBook, no desde los Markdown.

- Logo: `assets/brand/zbrou-logo.png`
- Color principal: `#0E58D8`
- Apariencia: oscuro, limpio y con el azul solo como acento.
- Usa **Site Variants** para los idiomas.
- Mantén Español como variante principal si ese será el idioma base de soporte.
- Si no quieres una barra de búsqueda protagonista, reduce su presencia desde la personalización del sitio.

## Git Sync

Cada carpeta de idioma (`es`, `en`, `pt`, etc.) está preparada como raíz de un Space independiente mediante su `.gitbook.yaml`.

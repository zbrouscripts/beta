# Descripción general

`zbrou_chat` sustituye el chat estándar de FiveM por un chat moderno y completamente personalizable. Está preparado para servidores PvP, roleplay o configuraciones mixtas sin obligarte a usar un modo concreto.

### Características

* Configuración completa desde el menú del juego.
* Varios estilos visuales y personalización para jugadores.
* Avatares de Discord opcionales.
* Mensajes de entrada, salida, bienvenida y mensajes automáticos.
* Comandos de chat globales o por proximidad.
* `/me` y `/do` configurables de forma independiente, con Texto3D opcional.
* Anuncios por jobs y comandos personalizados.
* Moderación con restricciones globales y mutes personales.
* Compatibilidad con el chat/exports de CFX para otros recursos.
* 7 idiomas incluidos.

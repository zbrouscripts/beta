# Frase Kill FiveM: detalles y términos relacionados

ZBrou FraseKill es un **script de FiveM para frases personalizadas al matar**, pensado para servidores PvP y roleplay que quieren mostrar un texto propio después de una baja. El sistema permite crear varios presets, cambiar tipografía, color, brillo, animación, posición y administrar quién puede utilizarlo.

## Cómo puede buscarse este tipo de script

Según el idioma o la forma de buscar de cada comunidad, este tipo de recurso también suele describirse como **FraseKill**, **PhraseKill**, **frase kill FiveM**, **kill phrase FiveM**, **custom kill message**, **kill text**, **death message**, **mensaje de muerte FiveM**, **mensaje al matar**, **texto al matar un jugador** o **frase personalizada de kill**. Todos esos términos se refieren a la misma idea general: personalizar el mensaje que aparece cuando un jugador elimina a otro.

## Qué permite hacer FraseKill

- Crear hasta 3 configuraciones completas por jugador.
- Usar un preset fijo o seleccionar uno de forma aleatoria.
- Personalizar frase, color, brillo, tamaño, tipografía, animación y posición.
- Mostrar una línea independiente con el nombre del jugador que realizó la kill.
- Dar acceso por jugador, ACE, job, gang/grupo, Tebex o integración personalizada.
- Gestionar accesos temporales, permanentes y caducidades desde administración.
- Integrarse con ESX, QBCore, Qbox o funcionar de forma standalone.

## Preguntas frecuentes

### ¿Cómo poner una frase al matar a un jugador en FiveM?
FraseKill añade un editor dentro del juego para crear el mensaje, configurar su estilo y decidir qué jugadores tienen acceso.

### ¿Es lo mismo FraseKill que PhraseKill o Kill Phrase?
Son formas diferentes de buscar el mismo concepto. El nombre del recurso es **ZBrou FraseKill**, pero términos como *PhraseKill*, *Kill Phrase*, *Kill Message* o *Kill Text* también se utilizan para scripts de mensajes personalizados después de una kill.

### ¿Funciona como mensaje de muerte o death message?
Sí. La víctima puede ver la frase configurada por el jugador que la eliminó, con posición, animación y estilo personalizados.

### ¿Se puede vender acceso con Tebex?
Sí. El sistema incluye accesos temporales o permanentes y puede integrarse con paquetes de Tebex para entregar o retirar permisos automáticamente.

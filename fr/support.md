# Support

Avant de demander du support, lancez `/frasekillstatus`, vérifiez la console et assurez-vous que `oxmysql` démarre avant FraseKill.

## Information to include

```text
FraseKill version: 1.0.0
Framework: ESX / QB / Qbox / Standalone
Medical resource:
Database: oxmysql
/frasekillstatus output:
Server console error:
F8 error:
```

Never publish database passwords, Tebex secrets or Discord webhook URLs in support messages.

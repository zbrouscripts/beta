# Kill Phrase FiveM : détails et termes associés

ZBrou FraseKill est un **script de message de kill personnalisé pour FiveM**, destiné aux serveurs PvP et roleplay qui souhaitent afficher un texte personnalisé après une élimination.

## Noms et recherches associés

Ce type de ressource peut aussi être recherché comme **FraseKill**, **PhraseKill**, **kill phrase FiveM**, **custom kill message FiveM**, **kill text**, **death message**, **message de mort FiveM**, **message après un kill** ou **texte de kill personnalisé**. Ces termes décrivent le même concept : personnaliser le message affiché après l’élimination d’un joueur.

## Fonctionnalités principales

- Jusqu’à 3 configurations complètes par joueur.
- Preset fixe ou sélection aléatoire.
- Texte, couleur, glow, taille, police, animation et position.
- Ligne séparée pour le nom du killer.
- Accès par joueur, ACE, job, gang/groupe, Tebex ou intégration custom.
- Accès temporaires ou permanents avec expiration.
- Compatibilité ESX, QBCore, Qbox et standalone.

## Questions fréquentes

### Comment ajouter un message personnalisé après un kill sur FiveM ?
FraseKill fournit un éditeur en jeu pour écrire le message, le prévisualiser et régler son style.

### FraseKill, PhraseKill et Kill Phrase désignent-ils la même chose ?
Ce sont des variantes de recherche courantes pour le même type de système. Le nom officiel de la ressource est **ZBrou FraseKill**.

### Peut-il servir de message de mort FiveM ?
Oui. La victime voit la phrase configurée par le killer avec animation, position et style personnalisés.

### Peut-on vendre l’accès avec Tebex ?
Oui. Les accès permanents ou temporaires peuvent être gérés via des packages Tebex.

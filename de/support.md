# Support

Vor einer Support-Anfrage `/frasekillstatus` ausführen, Serverkonsole prüfen und sicherstellen, dass `oxmysql` vor FraseKill startet.

## Information to include

```text
FraseKill version: 1.0.0
Framework: ESX / QB / Qbox / Standalone
Medical resource:
Database: oxmysql
/frasekillstatus output:
Server console error:
F8 error:
```

Never publish database passwords, Tebex secrets or Discord webhook URLs in support messages.

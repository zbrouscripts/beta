# FiveM Kill Phrase Script – ZBrou FraseKill

**ZBrou FraseKill** is a customizable FiveM kill phrase and death message script that displays a player-defined message after a kill. It covers common use cases searched as *kill phrase*, *custom kill message*, *kill text* or *death message*, with presets, animations, fonts, permissions and administration.

## Requirements

Required dependency: **oxmysql**. ESX, QBCore, Qbox and medical resources are optional. `zbrou_utils` is not a dependency.

## Features

- 3 complete presets per player.
- Fixed or random mode.
- 100 fonts.
- 25 animations plus no-animation mode.
- Color, glow, size, position and animation speed.
- Configurable killer-name line.
- 16:9, 16:10, 4:3, 5:4 and 21:9 preview.
- Access by player, ACE, jobs, gangs/groups, custom integrations and Tebex.
- Temporary or permanent access.
- Administration panel.
- ESX, QBCore, Qbox and standalone support.
- Configuration and access caching.

## Commands

```text
/frasekill
/frasekilladmin
/frasekillstatus
```

`/frasekilltest` existe solo para desarrollo y viene desactivado por defecto.

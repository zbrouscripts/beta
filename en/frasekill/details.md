# FiveM Kill Phrase Script: details and related terms

ZBrou FraseKill is a **FiveM custom kill message script** for PvP and roleplay servers that want to display personalized text after one player eliminates another. Players can save presets and customize fonts, colors, glow, animations, size and screen position.

## Common names and searches

Depending on the community, this type of resource may be searched as **FraseKill**, **PhraseKill**, **FiveM kill phrase**, **custom kill message FiveM**, **kill text FiveM**, **death message FiveM**, **custom death text**, **kill notification text** or **message after a kill**. These terms describe the same general idea: showing a customizable message after a player kill.

## What FraseKill can do

- Save up to 3 complete configurations per player.
- Use a fixed preset or select one randomly.
- Customize text, color, glow, size, font, animation and position.
- Display a separate killer-name line.
- Grant access by player, ACE, job, gang/group, Tebex or custom integrations.
- Manage permanent and temporary access with expiration.
- Integrate with ESX, QBCore, Qbox or run standalone.

## Frequently asked questions

### How do I add a custom kill message in FiveM?
FraseKill provides an in-game editor where players can write the message, preview it and configure the visual style.

### Are FraseKill, PhraseKill and Kill Phrase the same idea?
They are common search variations for the same type of system. The resource is called **ZBrou FraseKill**, while *PhraseKill*, *Kill Phrase*, *Kill Message* and *Kill Text* are also used for post-kill message scripts.

### Can it work as a FiveM death message?
Yes. The victim can see the killer's configured phrase with a custom animation, position and visual style.

### Can I sell FraseKill access through Tebex?
Yes. Permanent and time-limited access can be delivered and revoked through Tebex packages.

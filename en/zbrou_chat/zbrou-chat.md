# Overview

`zbrou_chat` replaces the default FiveM chat with a modern, highly customizable chat. It is designed for PvP, roleplay and mixed servers without forcing a specific server mode.

### Features

* Full in-game configuration.
* Multiple visual styles and player customization.
* Optional Discord avatars.
* Join, leave, welcome and automatic messages.
* Global and proximity chat commands.
* Independent `/me` and `/do` settings with optional 3D text.
* Job announcements and custom commands.
* Global moderation restrictions and personal mutes.
* CFX chat/export compatibility for external resources.
* 7 languages included.

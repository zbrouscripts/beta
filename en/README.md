## FiveM Kill Phrase Script – ZBrou FraseKill

**ZBrou FraseKill** is a customizable FiveM kill phrase and death message script that displays a player-defined message after a kill. It covers common use cases searched as *kill phrase*, *custom kill message*, *kill text* or *death message*, with presets, animations, fonts, permissions and administration.

### Quick start

```text
1. Install oxmysql
2. Add zbrou_frasekill
3. Configure permissions
4. ensure oxmysql
5. ensure zbrou_frasekill
```

# Frase Kill FiveM: detalhes e termos relacionados

ZBrou FraseKill é um **script de mensagem personalizada de kill para FiveM**, criado para servidores PvP e roleplay que querem mostrar um texto personalizado após uma eliminação.

## Nomes e buscas relacionadas

Este tipo de recurso também pode ser encontrado como **FraseKill**, **PhraseKill**, **frase kill FiveM**, **kill phrase FiveM**, **custom kill message**, **kill text**, **death message**, **mensagem de morte FiveM**, **mensagem ao matar** ou **texto de kill personalizado**. Todos descrevem a mesma ideia: personalizar a mensagem exibida depois que um jogador mata outro.

## O que o FraseKill oferece

- Até 3 configurações completas por jogador.
- Preset fixo ou modo aleatório.
- Texto, cor, brilho, tamanho, fonte, animação e posição.
- Linha separada com o nome do killer.
- Acesso por jogador, ACE, job, gang/grupo, Tebex ou integração custom.
- Acessos temporários ou permanentes com expiração.
- Compatibilidade com ESX, QBCore, Qbox e standalone.

## Perguntas frequentes

### Como colocar uma frase ao matar um jogador no FiveM?
FraseKill inclui um editor dentro do jogo para escrever a frase, visualizar o resultado e configurar o estilo.

### FraseKill, PhraseKill e Kill Phrase são a mesma coisa?
São variações comuns de busca para o mesmo tipo de sistema. O recurso se chama **ZBrou FraseKill**.

### Pode funcionar como mensagem de morte?
Sim. A vítima vê a frase configurada pelo killer com animação, posição e estilo personalizados.

### É possível vender acesso pelo Tebex?
Sim. O sistema suporta acessos permanentes e temporários entregues por pacotes Tebex.

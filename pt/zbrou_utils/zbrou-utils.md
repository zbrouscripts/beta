# Visão geral

`zbrou_utils` é a dependência partilhada dos recursos zbrou. Fornece o menu universal, configuração visual e funções comuns.

### Características

* Menu universal para recursos zbrou.
* Três estilos de interface.
* Tema claro/escuro e personalização visual.
* Seletor de idioma.
* Avatares do Discord opcionais.
* Cada recurso mantém os seus próprios dados e permissões.
